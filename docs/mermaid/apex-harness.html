🏗️ Hierarchical Task Distribution: Tier 0 → Tier 1 → Tier 2 → Tier 3

The orchestrator implements a 4-tier hierarchy for task delegation. Tier 0 (Director) decomposes macro goals into domain tasks. Tier 1 (Domain Orchestrators) route to specialized clusters. Tier 2 (Squad Leaders) coordinate worker fleets. Tier 3 (Workers) execute atomic tasks. Cost-aware model routing via Laya ensures optimal model selection per task.

Tier Responsibilities

Tier 0 — Director
Receives macro goals, decomposes into domain tasks, allocates cost budgets, monitors global progress
Tier 1 — Domain Orchestrators
Route tasks to specialized clusters (code, analysis, writing, governance), enforce domain-specific policies
Tier 2 — Squad Leaders
Coordinate worker fleets, manage wave-based dispatch, handle intra-squad escalation
Tier 3 — Workers
Execute atomic tasks using assigned model tier, report results with evidence

📋 P0-P4 Prioritization & Garbage Collection

Memory entries are scored on a 0.0–1.0 scale and classified into 5 priority tiers. The garbage collector uses composite eviction policies (TTL, LRU, LFU, staleness, relevance) with auto-GC at 90% capacity.

Auto-GC Trigger

Triggers at 90% capacity (9,000 entries of 10,000 max). Target: evict down to 80% (8,000 entries).

Decay Half-Life

24 hours. Recency score = exp(-age × ln(2) / half_life). Staleness penalty up to 30%.

Personalization

Per-user weight profiles with affinity tracking. Weights auto-tune based on interaction history.
